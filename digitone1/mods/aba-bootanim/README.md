# aba-bootanim (Digitone mk1 / Keys, OS 1.43)

An example **animated boot splash** generated by
[make-bootanim](../../../tools/make-bootanim) from
[`aba.gif`](../../../tools/make-bootanim/aba.gif) — 3 frames. Needs `core`
(core-dn1); install it **instead** of the hand-written splash mods (they patch
the same sites).

![aba on the Digitone](../../../screenshots/aba-dn1.gif)

## How it works

At each of the intro's panel-present call sites it copies the next packed frame
(1024 bytes each, `frames.bin`) over the frame the intro just composed, then
runs the stock present. It gates on the intro still owning PIT3, so nothing is
drawn over the UI. See [../../../docs/TECHNICAL.md](../../../docs/TECHNICAL.md)
and [../../../docs/PANEL-FORMAT.md](../../../docs/PANEL-FORMAT.md).

## Regenerate

```sh
tools\make-bootanim\make-bootanim.bat tools\make-bootanim\aba.gif --dn -o digitone1/mods/aba-bootanim
```

## Build and install

```sh
cd elekloader
python -m elekloader.sdk.build ../digitakt-splash-mods/digitone1/mods/aba-bootanim \
    --stock Digitone_and_Digitone_Keys_OS1.43.syx
python -m elekloader.patch --stock Digitone_and_Digitone_Keys_OS1.43.syx \
    --mod mods/core-dn1/out/core-dn1-2.0a.elemod \
    --mod ../digitakt-splash-mods/digitone1/mods/aba-bootanim/out/aba-1.0.elemod \
    --out aba-dn1.syx --version 2.0s
```
