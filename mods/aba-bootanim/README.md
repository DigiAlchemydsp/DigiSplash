# aba-bootanim

An example **animated boot splash** generated by
[make-bootanim](../../tools/make-bootanim) from
[`aba.gif`](../../tools/make-bootanim/aba.gif) — 3 frames. Needs `core`; install
it **instead** of the hand-written splash mods (they patch the same sites).

![aba on the Digitone](../../screenshots/aba-dn1.gif)

*(captured on a Digitone; the panel and the frames are identical.)*

## How it works

At each of the intro's panel-present call sites it copies the next packed frame
(1024 bytes each, `frames.bin`) over the frame the intro just composed, then
runs the stock present. It gates on the intro still owning PIT3, so nothing is
drawn over the UI. See [../../docs/TECHNICAL.md](../../docs/TECHNICAL.md) and
[../../docs/PANEL-FORMAT.md](../../docs/PANEL-FORMAT.md).

## Regenerate

```sh
tools\make-bootanim\make-bootanim.bat tools\make-bootanim\aba.gif -o mods/aba-bootanim
```

## Build and install

```sh
cd elekloader
python -m elekloader.sdk.build ../digitakt-splash-mods/mods/aba-bootanim --stock Digitakt_OS1.53.syx
python -m elekloader.patch --stock Digitakt_OS1.53.syx \
    --mod mods/core/out/core-2.1.elemod \
    --mod ../digitakt-splash-mods/mods/aba-bootanim/out/aba-1.0.elemod \
    --out aba.syx --version 2.0c
```
